1. قواعد البيانات وتطوير الويب (Databases and Web Development)

1.1 مقدمة (Introduction)

Original

This chapter covers the core principles of relational Database Management Systems (DBMSs). All database management systems are capable of: (1) managing large amounts of data, (2) maintaining data integrity, (3) responding to many queries, (4) creating indexes and triggers, and more. The term database can refer to both the software (i.e., to the DBMS) and to the data that is managed by the DBMS.

الترجمة: يغطي هذا الشابتر المبادئ الأساسية لأنظمة إدارة قواعد البيانات العلائقية (DBMSs). جميع أنظمة إدارة قواعد البيانات قادرة على: (1) إدارة كميات كبيرة من البيانات، (2) الحفاظ على سلامة البيانات، (3) الاستجابة للعديد من الاستعلامات، (4) إنشاء الفهارس والمحفزات، والمزيد. مصطلح "قاعدة بيانات" يمكن أن يشير إلى كل من البرمجيات (أي DBMS) والبيانات التي يديرها DBMS.

أنظمة إدارة قواعد البيانات العلائقية الشائعة:

  • PostgreSQL
  • Oracle Database
  • IBM DB2
  • Microsoft SQL Server
  • MySQL

1.2 دور قواعد البيانات في تطوير الويب (The Role of Databases in Web Development)

Original

Databases provide a way to implement one of the most important software design principles: Content (data) varies but the markup (design) stays the same.

الترجمة: توفر قواعد البيانات طريقة لتطبيق أحد أهم مبادئ تصميم البرمجيات: المحتوى (البيانات) يتغير لكن الهيكل (التصميم) يبقى كما هو.

1.3 تصميم قاعدة البيانات — الجداول (Database Design — Tables)

Original

A database in a Relational DBMS is composed of one or more tables. A table is a two-dimensional container for data that consists of records (rows). Each record has the same number of columns, which are called fields, which contain the actual data. Each table will have one special field called a primary key that is used to uniquely identify each record in a table.

الترجمة: قاعدة البيانات في DBMS العلائقي تتكون من جدول واحد أو أكثر. الجدول هو حاوية ثنائية الأبعاد للبيانات تتكون من سجلات (Records / Rows). كل سجل له نفس عدد الأعمدة، والتي تُسمى حقول (Fields)، وتحتوي البيانات الفعلية. كل جدول سيكون له حقل خاص واحد يُسمى المفتاح الأساسي (Primary Key) يُستخدم لتمييز كل سجل في الجدول بشكل فريد.

1.4 فوائد DBMS — أنواع البيانات (DBMS Benefits — Data Types)

Original

A database can enforce rules about what can be stored. This provides data integrity and potentially can reduce the amount of data duplication. This is partly achieved through the use of data types that are like those in a programming language to avoid data duplication and full integrity.

الترجمة: يمكن لقاعدة البيانات فرض قواعد حول ما يمكن تخزينه. هذا يوفر سلامة البيانات (Data Integrity) وربما يقلل من كمية تكرار البيانات. يتحقق ذلك جزئيًا من خلال استخدام أنواع البيانات المشابهة لتلك الموجودة في لغة البرمجة لتجنب تكرار البيانات والسلامة الكاملة.

أنواع البيانات الشائعة في جداول قواعد البيانات

النوع الوصف

BLOB يمثل كائنًا ثنائيًا كبيرًا (Binary Large Object) — يمكن استخدامه لتخزين الصور مثلًا.
CHAR(n) عدد ثابت من الأحرف (n) مع حشو بمسافات لملء الحقل.

VARCHAR(n) عدد متغير من الأحرف (n = الحد الأقصى) بدون حشو بمسافات.

1.5 العلاقات بين الجداول (Relationships between Tables)

Original

One of the most important ways that data integrity is achieved in a database is by separating information about different things into different tables. Two tables can be related together via foreign keys, which is a field that is the same as the primary key of another table.

الترجمة: واحدة من أهم طرق تحقيق سلامة البيانات في قاعدة البيانات هي فصل المعلومات عن الأشياء المختلفة في جداول مختلفة. يمكن ربط جدولين معًا عبر المفاتيح الأجنبية (Foreign Keys)، وهو حقل مطابق للمفتاح الأساسي لجدول آخر.

1.6 خيارات قواعد البيانات (Database Options)

Original

SQLite: A software library or a relational database management system contained in C that typically is integrated directly within an application rather than running as a separate process like most DBMS. Approach for web developers. NoSQL databases: Do not make use of SQL, are not relational in how they store data, and are optimized to retrieve data using simple key-value syntax similar to that used with associative arrays in PHP (CouchDB, MongoDB, Hypertable, Cassandra, ...).

الترجمة:

  • SQLite: مكتبة برمجية أو نظام إدارة قواعد بيانات علائقية مكتوب بلغة C، يُدمج عادةً مباشرة داخل التطبيق بدلًا من العمل كعملية منفصلة مثل معظم أنظمة DBMS. نهج مطورو الويب.
  • قواعد بيانات NoSQL: لا تستخدم SQL، وليست علائقية في طريقة تخزينها للبيانات، ومُحسّنة لاسترداد البيانات باستخدام صيغة بسيطة key-value مشابهة لتلك المستخدمة مع المصفوفات الترابطية في PHP (CouchDB، MongoDB، Hypertable، Cassandra، ...).

2. لغة الاستعلام الهيكلية (Structured Query Language — SQL)

The Four Core SQL Statements

  1. SELECT — retrieve data
  2. INSERT — add data
  3. UPDATE — modify data
  4. DELETE — remove data

الترجمة: أربعة أوامر SQL الأساسية:

  1. SELECT — استرجاع البيانات.
  2. INSERT — إضافة البيانات.
  3. UPDATE — تعديل البيانات.
  4. DELETE — حذف البيانات.

2.1 SELECT — استرجاع البيانات

Original

The SELECT statement is used to retrieve data from the database. The result of a SELECT statement is a block of data typically called a result set. You must specify what fields to retrieve and what table to retrieve from.

الترجمة: يُستخدم أمر SELECT لاسترجاع البيانات من قاعدة البيانات. نتيجة أمر SELECT هي كتلة بيانات تُسمى عادةً مجموعة النتائج (Result Set). يجب تحديد الحقول التي تريد استرجاعها والجدول الذي تريد الاسترجاع منه.

Basic SELECT

SELECT ISBN10, Title FROM Books;
  • SELECT — SQL keyword يشير إلى نوع الاستعلام (استرجاع البيانات).
  • ISBN10, Title — الحقول المطلوب استرجاعها.
  • FROM — SQL keyword لتحديد الجدول.
  • Books — الجدول الذي نستعلم منه.

Wildcard — SELECT *

SELECT * FROM Books;

Wildcard (الرمز *) — يختار جميع الحقول.

تنبيه مهم: على الرغم من أن الرمز * مريح — خاصةً أثناء الاختبار — إلا أنه في كود الإنتاج عادةً يتم تجنبه. بدلًا من تحديد كل حقل، يجب تحديد الحقول التي تحتاجها فقط.

2.2 ORDER BY — ترتيب النتائج

Original

To specify a certain order to the result set use the ORDER BY clause. You specify: the field to sort on (or several), and whether to sort in ascending or descending order.

الترجمة: لتحديد ترتيب معين لمجموعة النتائج، استخدم جملة ORDER BY. تحدد: الحقل الذي تريد الترتيب عليه (أو عدة حقول)، وما إذا كنت تريد الترتيب تصاعديًا (ASC) أو تنازليًا (DESC).

ORDER BY Example

SELECT ISBN10, Title
FROM Books
ORDER BY Title;

Multiple Sort Orders

SELECT ISBN10, Title
FROM Books
ORDER BY CopyrightYear DESC, Title ASC;

الترجمة: في هذا المثال، يتم ترتيب البيانات أولًا حسب CopyrightYear تنازليًا، ثم حسب Title تصاعديًا.

📌 ملاحظة مهمة:

SQL لا يهتم إذا كان الأمر في سطر واحد أو عدة أسطر، ولا يهتم بحالة الأحرف (الكبيرة/الصغيرة) للكلمات المفتاحية أو أسماء الجداول والحقول. فواصل الأسطر وكتابة الكلمات المفتاحية بأحرف كبيرة تُستخدم غالبًا للمساعدة في القراءة.

2.3 WHERE — تصفية النتائج

Original

The simple SELECT queries used so far retrieve all the records in the specified table. Often we are not interested in retrieving all the records in a table but only a subset of the records. This is accomplished via the WHERE clause, which can be added to any SELECT statement.

الترجمة: استعلامات SELECT البسيطة التي استخدمناها حتى الآن تسترجع جميع السجلات في الجدول المحدد. غالبًا لا نهتم باسترجاع جميع السجلات في جدول، بل فقط مجموعة فرعية منها. يتحقق ذلك عبر جملة WHERE، والتي يمكن إضافتها إلى أي أمر SELECT.

WHERE with numeric comparison

SELECT isbn10, title
FROM books
WHERE copyrightYear > 2010;

WHERE with multiple conditions

SELECT isbn10, title
FROM books
WHERE category = 'Math' AND copyrightYear = 2014;

ملاحظة: المقارنات مع النصوص تتطلب string literals (علامات تنصيص مفردة أو مزدوجة).

2.4 INNER JOIN — دمج جداول

Original

Often we want to retrieve data from multiple tables. While we could do one query, and then do a second query using the data from the 1st query, that would be inefficient. Instead we can use the JOIN clause (we will discuss INNER JOIN).

الترجمة: غالبًا ما نريد استرجاع بيانات من جداول متعددة. على الرغم من أننا نستطيع تنفيذ استعلام واحد، ثم استعلام آخر باستخدام بيانات الاستعلام الأول، إلا أن ذلك سيكون غير فعّال. بدلًا من ذلك، يمكننا استخدام جملة JOIN (سنتناول INNER JOIN).

INNER JOIN — ArtWorks + Artists

SELECT Artists.ArtistID, Title, YearOfWork, Name
FROM Artists
INNER JOIN ArtWorks ON Artists.ArtistID = ArtWorks.ArtistID
  • INNER JOIN — SQL keywords تشير إلى نوع الدمج.
  • ArtWorks — الجدول الثاني.
  • Artists.ArtistID — المفتاح الأساسي في الجدول الأول.
  • ArtWorks.ArtistID — المفتاح الأجنبي في الجدول الثاني.

ملاحظة: لأن اسم الحقل ArtistID غامض (موجود في جدولي)، يجب تسبيقه باسم الجدول.

INNER JOIN — Books + Authors (via intermediate table)

SELECT Books.BookID, Books.Title, Authors.Name, Books.CopyrightYear
FROM Books
INNER JOIN BookAuthors ON Books.BookID = BookAuthors.BookID
INNER JOIN Authors     ON Authors.AuthorID = BookAuthors.AuthorID

الترجمة: هذا المثال يدمج جدولين عبر جدول وسيط (BookAuthors) لتنفيذ علاقة Many-to-Many بين Books و Authors.

2.5 GROUP BY — التجميع مع دوال التجميع

Original

When you don't want every record in your table but instead want to perform some type of calculation on multiple records and then return the results. This requires using one or more aggregate functions such as SUM() or COUNT(); these are often used in conjunction with the GROUP BY keywords.

الترجمة: عندما لا تريد كل سجل في الجدول، بل تريد تنفيذ نوع من الحساب على سجلات متعددة ثم إرجاع النتائج. هذا يتطلب استخدام دالة تجميع واحدة أو أكثر مثل SUM() أو COUNT()؛ غالبًا ما تُستخدم هذه مع الكلمات المفتاحية GROUP BY.

Aggregate without GROUP BY — single result

SELECT COUNT(ArtWorkID) AS NumPaintings
FROM ArtWorks
WHERE YearOfWork > 1900;

الناتج:

NumPaintings
745

الترجمة: هذه الجملة ترجع سجلًا واحدًا بقيمة واحدة (عدد اللوحات بعد عام 1900).

GROUP BY with COUNT — multiple results

SELECT Nationality, COUNT(ArtistID) AS NumArtists
FROM Artists
GROUP BY Nationality;

الناتج:

NationalityNumArtists
Belgium4
England15
France36
Germany27
Italy53

الترجمة: هذه الجملة ترجع عدد سجلات مساوٍ لعدد القيم الفريدة في الحقل المُجمَّع عليه (Nationality).

2.6 INSERT — إضافة البيانات

Original

INSERT INTO ArtWorks (Title, YearOfWork, ArtistID)
VALUES ('Night Watch', 1642, 105)

الترجمة: جملة INSERT تُضيف سجلًا جديدًا (صفًا) إلى الجدول.

  • INSERT INTO — SQL keywords للإدراج (إضافة) سجل جديد.
  • ArtWorks — اسم الجدول.
  • (Title, YearOfWork, ArtistID) — الحقول التي ستستقبل القيم.
  • VALUES ('Night Watch', 1642, 105) — القيم المطلوب إدراجها.

📌 ملاحظات مهمة:

  • قيم النصوص يجب أن تكون داخل علامات تنصيص (مفردة أو مزدوجة).
  • حقول المفتاح الأساسي غالبًا ما تكون AUTO_INCREMENT — أي سيقوم DBMS بتعيين قيمة فريدة تلقائيًا عند إدراج سجل جديد.

2.7 UPDATE — تعديل البيانات

Original

UPDATE ArtWorks
SET Title='Night Watch', YearOfWork=1642, ArtistID=105
WHERE ArtWorkID=54

الترجمة: جملة UPDATE تُعدّل بيانات سجل موجود.

⚠️ تنبيه خطير: من الضروري تحديد أي سجل تريد تعديله (عبر WHERE)، وإلا فسيتم تحديث جميع السجلات في الجدول!

ملاحظة: الحقول التي تكون AUTO_INCREMENT لا يمكن تعديل قيمها.

2.8 DELETE — حذف البيانات

Original

DELETE FROM ArtWorks WHERE ArtWorkID=54

الترجمة: جملة DELETE تحذف صفوفًا من الجدول.

⚠️ تنبيه خطير: من الضروري تحديد أي سجل تريد حذفه (عبر WHERE)، وإلا فسيتم حذف جميع السجلات!

2.9 المعاملات (Transactions)

Original

Anytime one of your PHP pages makes changes to the database via an UPDATE, INSERT, or DELETE statement, you also need to be concerned with the possibility of failure. A transaction refers to a sequence of steps that are treated as a single unit, and provide a way to gracefully handle errors and keep your data properly consistent when errors do occur.

الترجمة: في أي وقت يقوم فيه أحد صفحات PHP بإجراء تغييرات على قاعدة البيانات عبر UPDATE أو INSERT أو DELETE، يجب أن تكون قلقًا أيضًا بشأن احتمال الفشل. تشير المعاملة (Transaction) إلى تسلسل من الخطوات تُعامَل كوحدة واحدة، وتوفر طريقة للتعامل مع الأخطاء بأناقة والحفاظ على اتساق البيانات بشكل صحيح عند حدوث الأخطاء.

الترجمة: أوامر SQL للمعاملات:

  • START TRANSACTION — بدء المعاملة.
  • COMMIT — تأكيد التغييرات وجعلها دائمة.
  • ROLLBACK — التراجع عن التغييرات وإلغاؤها.

2.10 فهارس قاعدة البيانات (Database Indexes)

Original

In large sets of data, searching for a particular record can take a long time. Consider the worst-case scenario for searching where we compare our query against every single record. If there are n elements we say it takes O(n) time to do a search (we would say "Order of n"). In comparison, a balanced binary tree data structure can be searched in O(log₂ n) time.

الترجمة: في مجموعات البيانات الكبيرة، يمكن أن يستغرق البحث عن سجل معين وقتًا طويلًا. اعتبر السيناريو الأسوأ للبحث حيث نقارن استعلامنا مع كل سجل. إذا كانت هناك n من العناصر، نقول إن البحث يستغرق وقتًا O(n). في المقابل، يمكن البحث في بنية شجرة ثنائية متوازنة في وقت O(log₂ n).

Original — A vulnerable form

كيف يعمل هجوم حقن SQL؟

1

Vulnerable Form

نموذج ضعيف يمرر مدخلات غير معقمة مباشرة إلى استعلامات SQL.

2

Hacker Inputs SQL

المخترق يُدخل كود SQL في حقل نصي ويُرسل النموذج (مثل: '; TRUNCATE TABLE Users; #).

3

PHP Builds Query

سكريبت PHP يضع الحقول الخام مباشرة في استعلام SQL.

4

Malicious Query Executes

الاستعلام الناتج هو في الواقع استعلامان: الأول عادي والثاني خبيث.

5

Data Destroyed

حذف جميع السجلات من الجدول (TRUNCATE أو DROP).

⚠️ خطير: مثال على هجوم حقن SQL — إذا أدخل المهاجم في حقل اسم المستخدم: '; TRUNCATE TABLE Users; # — فإن الاستعلام النهائي يصبح:

SELECT * FROM Users WHERE uname='' ;
TRUNCATE TABLE Users;
# ' AND passwd=MD5('pass')

الجزء بعد # هو تعليق، فيُنفَّذ الاستعلامان: الأول لا يُرجع شيئًا، والثاني يحذف كل السجلات.

5.6 الدفاع ضد الهجوم — تنقية المدخلات (Sanitizing User Input)

Original

The SQL injection class of attack can be protected against by: (1) Sanitizing user input, (2) Using Prepared Statements. The process of checking user input for incorrect or missing information and examining SQL injection attacks is sometimes referred to as the process of sanitizing user inputs. Distrust all user inputs.

الترجمة: يمكن الحماية ضد فئة هجوم حقن SQL عبر: (1) تنقية مدخلات المستخدم، (2) استخدام الاستعلامات المحضرة. عملية التحقق من مدخلات المستخدم بحثًا عن معلومات غير صحيحة أو مفقودة وفحص هجمات حقن SQL تُسمى أحيانًا عملية تنقية مدخلات المستخدم. لا تثق بأي مدخلات من المستخدم.

In MySQL — mysqli_real_escape_string() or PDO's quote()

5.7 الاستعلامات المحضرة (Prepared Statements)

Original

A prepared statement is actually a way to improve performance for queries that need to be executed multiple times. When MySQL creates a prepared statement, it does something akin to a compiler in that: (1) it optimizes it so that it has superior performance for multiple requests, (2) It also integrates sanitization into each user input automatically, thereby protecting us from SQL injection.

الترجمة: الاستعلام المحضر (Prepared Statement) هو في الواقع وسيلة لتحسين الأداء للاستعلامات التي تحتاج إلى تنفيذها عدة مرات. عندما ينشئ MySQL استعلامًا محضرًا، فإنه يفعل شيئًا مشابهًا للمترجم حيث: (1) يُحسّنه بحيث يكون له أداء فائق للطلبات المتعددة، (2) يدمج أيضًا التنقية في كل إدخال من المستخدم تلقائيًا، مما يحمينا من حقن SQL.

mysqli — Prepared Statements

<?php
// retrieve parameter value from query string
$id = $_GET['id'];

// construct parameterized query - notice the ? parameter
$sql = "SELECT Title, CopyrightYear FROM Books WHERE ID=?";

// create a prepared statement
if ($statement = mysqli_prepare($connection, $sql)) {

    // Bind parameters: s - string, b - blob, i - int, etc
    mysqli_stmt_bind_param($statement, 'i', $id);

    // execute query
    mysqli_stmt_execute($statement);

    // learn in next section how to access the returned data
}
?>

5.10 استخدام المعاملات في PHP (Using Transactions in PHP)

PDO — Transactions

$pdo = new PDO($connString, $user, $pass);

// turn on exceptions so that exception is thrown
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

try {
    // begin a transaction
    $pdo->beginTransaction();

    // a set of queries: if one fails, an exception will be thrown
    $pdo->query("INSERT INTO Categories (CategoryName) VALUES ('Philosophy')");
    $pdo->query("INSERT INTO Categories (CategoryName) VALUES ('Art')");

    // if we arrive here, it means that no exception was thrown
    // which means no query has failed, so we can commit the transaction
    $pdo->commit();
}
catch (Exception $e) {
    // we must rollback the transaction since an error occurred
    $pdo->rollback();
}

الترجمة: يمكن استخدام المعاملات في PDO عبر: beginTransaction() و commit() و rollback().

7.1 عرض قائمة روابط (Display a List of Links)

Original

One of the most common database tasks in PHP is to display a list of links (i.e., a series of <li> elements within a <ul>).

الترجمة: واحدة من أكثر مهام قواعد البيانات شيوعًا في PHP هي عرض قائمة روابط (أي سلسلة من عناصر <li> داخل <ul>).

Output — HTML List

<ul>
  <li><a href="list.php?category=7">Business</a></li>
  <li><a href="list.php?category=2">Computer Science</a></li>
  <li><a href="list.php?category=3">Economics</a></li>
  <li><a href="list.php?category=9">Engineering</a></li>
  <li><a href="list.php?category=4">English</a></li>
  <li><a href="list.php?category=6">Mathematics</a></li>
  <li><a href="list.php?category=8">Statistics</a></li>
  <li><a href="list.php?category=5">Student Success</a></li>
</ul>

PHP Code

$sql = "SELECT * FROM Categories ORDER BY CategoryName";
$result = $pdo->query($sql);

echo "<ul>";
while ($row = $result->fetch()) {
    echo "<li><a href='list.php?category=" . $row['ID'] . "'>"
         . $row['CategoryName'] . "</a></li>";
}
echo "</ul>";

7.2 صفحة البحث والنتائج (Search and Results Page)

Original

In this example, we will assume that there is a text box with the name txtSearch in which the user enters a search string along with a Submit button. The data that we will filter is the Book table; we will display any book records that contain the user-entered text in the Title field.

الترجمة: في هذا المثال، سنفترض وجود مربع نص باسم txtSearch يُدخل فيه المستخدم سلسلة البحث مع زر إرسال. البيانات التي سنُصفّيها هي جدول Books؛ سنعرض أي سجلات كتب تحتوي على النص الذي أدخله المستخدم في حقل Title.

Search Page — HTML Form

<form method="get">
  <input type="search"
         name="txtSearch"
         placeholder="Enter search string"
         value="<?php echo $_GET['txtSearch']; ?>" />
  <input type="submit" value="Search" />
</form>

Search Query — with wildcards and prepared statement

<?php
// add SQL wildcard characters to search term
$searchFor = '%' . $_GET['txtSearch'] . '%';

$sql = "SELECT * FROM Books WHERE Title LIKE ?";
$statement = $pdo->prepare($sql);
$statement->bindValue(1, $searchFor);
$statement->execute();

while ($row = $statement->fetch()) {
    echo $row['Title'] . "<br/>";
}
?>

📌 ملاحظات:

  • استخدام % قبل وبعد نص البحث يعني "أي نص يحتوي على السلسلة".
  • استخدام LIKE يجعل البحث غير حساس لحالة الأحرف في معظم أنظمة قواعد البيانات.
  • في حال عدم وجود نتائج مطابقة، لن يُعرض شيء. يمكن إضافة رسائل خطأ لاحقًا.

7.3 تخزين الملفات في قاعدة البيانات (Files in the Database)

Original

There are two ways of storing files in a database: (1) Storing file location in the database, and storing the file on the server's filesystem. (2) Storing the file itself in the database in the form of a binary BLOB.

الترجمة: هناك طريقتان لتخزين الملفات في قاعدة البيانات:

  1. تخزين مسار الملف في قاعدة البيانات، وتخزين الملف نفسه على نظام ملفات الخادم.
  2. تخزين الملف نفسه في قاعدة البيانات في صورة BLOB ثنائي (Binary Large Object).

الطريقة 1 — تخزين المسار فقط

جدول يخزن المسار

IDUIDPathImageContent
28035/images/983412824.jpg...
1

User uploads file

المستخدم يرفع ملفًا عبر نموذج <form enctype="multipart/form-data" method="post">.

2

PHP retrieves from $_FILES

سكريبت PHP يسترجع الملف من $_FILES ويعطيه اسمًا فريدًا وينقله إلى موقع خاص.

3

Save path in database

PHP يحفظ مسار الملف في جدول قاعدة البيانات.

4

Future requests

الطلبات المستقبلية للصورة تتم عبر مسار الملف مباشرة: <img src="/images/983412824.jpg">.

الطريقة 2 — تخزين BLOB

جدول يخزن BLOB

IDUIDPathImageContent (BLOB)
28035...[binary data...]
1

User uploads file

المستخدم يرفع ملفًا.

2

PHP saves BLOB

PHP يسترجع الملف من $_FILES ويحفظ بيانات BLOB في قاعدة البيانات.

3

Future requests via intermediary script

الطلبات المستقبلية تمر عبر سكريبت وسيط باستخدام ID.

4

السكريبت يسترجع بيانات BLOB ويعرضها كـ Content-type: image/jpeg.

Listing 11.35 — Save file contents in a BLOB field

$fileContent = file_get_contents("someImage.jpg");
$sql = "INSERT INTO TravelImage (ImageContent) VALUES (:data)";

$statement = $pdo->prepare($sql);
$statement->bindParam(':data', $fileContent, PDO::PARAM_LOB);
$statement->execute();

Listing 11.36 — Fetch and echo BLOB image

// retrieve blob content from database
$sql = "SELECT * FROM TravelImage WHERE ImageID=:id";
$statement = $pdo->prepare($sql);
$statement->bindParam(':id', $_GET['id']);
$statement->execute();

$result = $statement->fetch(PDO::FETCH_ASSOC);
if ($result) {
    // Output the MIME header
    header("Content-type: image/jpeg");

    // Output the image
    echo ($result["ImageContent"]);
}

📊 مقارنة سريعة — أيهما أسرع وأكثر أمانًا؟

وجه المقارنة تخزين المسار (Filesystem) تخزين BLOB (Database)
السرعة ✅ أسرع (الخادم يقدم الملف مباشرة) ⚠️ أبطأ (يمر عبر سكريبت PHP)
النسخ الاحتياطي ⚠️ معقد (ملفات + قاعدة بيانات) ✅ بسيط (قاعدة بيانات واحدة)
الأمان ⚠️ يعتمد على إعدادات الخادم ✅ يمكن حماية الوصول عبر الصلاحيات
الأداء مع الملفات الكبيرة ✅ جيد ⚠️ قد يؤثر على قاعدة البيانات

16. Transaction

English Term
Transaction
النطق بالعربية
تْرَانْزَاكْشِن
Definition in English
A sequence of database operations treated as a single logical unit that either all succeed or all fail.
النطق بالعربية للتعريف
أ سِيكْوِنْس أوف دَاتَابِيس أُوبِرِيشِنْز تْرِيتِد آز أ سِنْغِل لُوجِكَال يُونِت ذَت إِيذَر أول سَكْسِيد أُور أول فَايْل.

معاملة.
الشرح المبسط

17. Index

English Term
Database Index
النطق بالعربية
دَاتَابِيس إنْدِكْس
Definition in English
A data structure (often a balanced tree) that speeds up data retrieval, with search time of O(log₂ n) instead of O(n).
النطق بالعربية للتعريف
أ دَاتَا سْتْرَكْشَر (أُوفِن أ بَالَنْسْت تْرِي) ذَت سْبِيدْز أب دَاتَا رِيتْرِيفَال، وِذ سِيرْتش تَايْم أوف أو-لُوج-تُو-إن إنْسْتِيد أوف أو-إن.
الترجمة العربية
فهرس قاعدة البيانات.
الشرح المبسط
هيكل يسرّع البحث باستخدام شجرة متوازنة.

18. BLOB

English Term
BLOB (Binary Large Object)
النطق بالعربية
بْلُوب
Definition in English
A data type used to store large binary data such as images or files inside a database.
النطق بالعربية للتعريف
أ دَاتَا تَايْب يُوزْد تو سْتُور لَارْج بَايْنَرِي دَاتَا سَاتْش آز إِمِيجِز أُور فَايْلْز إنْسَايْد أ دَاتَابِيس.
الترجمة العربية
كائن ثنائي كبير.
الشرح المبسط
نوع بيانات لتخزين الملفات الكبيرة داخل قاعدة البيانات.
