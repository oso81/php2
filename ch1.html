1. ما هو تطوير جانب الخادم (What is Server-Side Development)

1.1 التعريف الأساسي

Definition — Original

If you have a set of files or a file, you think you should host them on a web server. The basic hosting of your files is achieved through a web server. Server-side development involves the use of a programming technology like PHP or ASP.NET to create scripts (code) that dynamically generate content.

الترجمة: إذا كانت لديك مجموعة ملفات أو ملف واحد، فأنت تفكر في استضافتها على خادم ويب. الاستضافة الأساسية للملفات تتم عبر خادم الويب. تطوير جانب الخادم يتضمن استخدام تقنية برمجية مثل PHP أو ASP.NET لإنشاء سكربتات (أكواد) تولّد المحتوى ديناميكيًا.

1.2 تنفيذ سكربت العميل مقابل سكربت الخادم (Client Script vs Server Script)

(a) Client Script Execution — تنفيذ سكربت العميل

  1. Request for JavaScript source file — طلب ملف JavaScript.
  2. script.js — الخادم يُرجع الملف إلى المتصفح.
  3. Execute any JavaScript as required — المتصفح ينفذ كود JavaScript.
  4. Display in browser — النتيجة تُعرض للمستخدم.

(b) Server Script Execution — تنفيذ سكربت الخادم

  1. Request for PHP resource — طلب مورد PHP.
  2. PHP code in requested resource is executed — كود PHP في المورد المطلوب يُنفَّذ على الخادم.
  3. Output from PHP execution — ناتج تنفيذ PHP يُرجع إلى خادم الويب.
  4. Display in browser — النتيجة تُعرض في المتصفح.

📌 الفرق الجوهري:

  • Client-side: الكود يُنفَّذ داخل المتصفح (JavaScript) — يمكن للمستخدم رؤيته وتعديله.
  • Server-side: الكود يُنفَّذ على الخادم (PHP) — المستخدم يرى النتيجة فقط.

Original

There are so many tools in your kit. These resources can be categorized as data storage resources, web services, and software applications.

الترجمة: هناك أدوات كثيرة في صندوق أدواتك. يمكن تصنيف هذه الموارد إلى: موارد تخزين بيانات، وخدمات ويب، وتطبيقات برمجية.

1.4 تقنيات تطوير الويب (Web Development Technologies)

يوضح الشابتر مخططًا مفاده أن نفس الصفحة يمكن تنفيذها بتقنيات مختلفة، مثال: vacation.php (PHP) و vacation.aspx (ASP.NET):

الخطوات الأربع للتنفيذ

  1. GET /vacation.php (or .aspx) — طلب من المتصفح إلى خادم الويب.
  2. Execute program/script — الخادم ينفذ السكربت بلغة PHP أو ASP.NET.
  3. Program outputs HTML (and possibly JavaScript and CSS) — الناتج HTML + JS + CSS.
  4. Program output is sent back in HTTP response — الناتج يُرسل للمتصفح كاستجابة HTTP.

1.5 مقارنة تقنيات جانب الخادم (Comparing Server-Side Technologies)

ASP (Active Server Pages)

Like PHP, ASP code (using VBScript) can be embedded within HTML. It is interpreted at run time, hence it can be slow compared to other technologies.

الترجمة: مثل PHP، يمكن تضمين كود ASP (بلغة VBScript) داخل HTML. يُفسَّر في وقت التشغيل، مما قد يجعله بطيئًا مقارنة بتقنيات أخرى.

ASP.NET

Part of Microsoft's .NET Framework, can use any .NET language (C# common). Uses explicit object-oriented approach. Uses web server controls. Compiled into MSIL (like Java bytecode), then JIT-compiled. Excellent performance but Windows-only.

الترجمة: جزء من إطار .NET لمايكروسوفت، يمكنه استخدام أي لغة .NET (C# هي الشائعة). يتبع نهجًا كائني التوجه صريحًا. يستخدم عناصر تحكم خادم الويب. يُجمَّع إلى MSIL (مثل Java bytecode)، ثم يُجمَّع بـ JIT. أداؤه ممتاز لكنه مخصص لـ Windows فقط.

JSP (Java Server Pages)

Uses Java, object-oriented, integrated into J2EE, uses JIT for fast execution, cross-platform. Small web usage but substantial in intranets and large sites.

الترجمة: تستخدم Java، كائنية التوجه، مدمجة في بيئة J2EE، تستخدم JIT لتنفيذ سريع، ومتعددة المنصات. استخدامها قليل في الويب العام لكنه كبير في الشبكات الداخلية والمواقع الضخمة.

Node.js

Uses JavaScript on the server side. Developers use a single language for both sides. Unlike others, node.js is its own web server software (no Apache/IIS needed).

الترجمة: يستخدم JavaScript على جانب الخادم. المطورون يستخدمون لغة واحدة للجانبين. على عكس التقنيات الأخرى، Node.js خادم ويب بحد ذاته (لا يحتاج Apache أو IIS).

Perl

Used for early server-side development. Excels in text manipulation. Used with CGI (an early standard API).

الترجمة: استُخدمت في تطوير الويب المبكر. ممتازة في معالجة النصوص. استُخدمت مع CGI (واجهة برمجية معيارية قديمة للتواصل بين التطبيقات وخوادم الويب).

PHP

Dynamically typed, embedded directly within HTML, supports OOP (classes and inheritance). Compiled into opcodes (like Java bytecode). Originally "Personal Home Pages," now "PHP: Hypertext Processor."

الترجمة: ديناميكية النوع، تُدمج مباشرة داخل HTML، تدعم OOP (الأصناف والوراثة). تُجمَّع إلى opcodes (مثل Java bytecode). كانت تعني "Personal Home Pages"، والآن تعني "PHP: Hypertext Processor".

Python

Object-oriented language, used in web frameworks like Django and Pyramid.

الترجمة: لغة كائنية التوجه، تُستخدم في أطر تطوير الويب مثل Django و Pyramid.

Ruby on Rails

Web development framework using Ruby. Follows MVC design pattern. Integrates templates and engines to reduce development work.

الترجمة: إطار تطوير ويب يستخدم لغة Ruby. يتبع نمط تصميم MVC. يدمج القوالب والمحركات لتقليل جهد التطوير.

You will be using the LAMP/WAMP software stack. W for ???!! — Linux operating system, Apache web server, MySQL DBMS, PHP scripting language.

2.3 Apache and Linux

Original

Consider the Apache web server as the intermediary that interprets HTTP requests that arrive through a network port and decides how to handle the request, which often requires working in conjunction with PHP.

الترجمة: اعتبر خادم Apache الوسيط الذي يفسّر طلبات HTTP الواردة عبر منفذ شبكة، ويقرر كيفية معالجة الطلب — غالبًا بالتعاون مع PHP.

  • Port (e.g. 80) — منفذ الشبكة (مثل 80) الذي تستقبل عليه طلبات HTTP.
  • php.ini — ملف إعدادات PHP.
  • httpd.conf — ملف إعدادات Apache الرئيسي.
  • .htaccess — ملف إعدادات إضافي لكل مجلد على حدة.

The easiest and quickest way to install LAMP locally is to use one of these packages: EasyPHP (Windows only), XAMPP (Windows), MAMP (Mac), WampServer (Windows). All of these install and configure Apache, PHP, and MySQL.

2.5 WampServer

Original

WampServer = Apache + PHP + MySQL on Windows. Available at http://www.wampserver.com/en/. Provides an interface to manage services (Start/Stop/Restart), MySQL console, phpMyAdmin, www directory.

الترجمة: WampServer = Apache + PHP + MySQL على Windows. متاح على http://www.wampserver.com/en/. يوفر واجهة لإدارة الخدمات (تشغيل/إيقاف/إعادة تشغيل)، ووحدة تحكم MySQL، وphpMyAdmin، ومجلد www.

2.6 XAMPP Settings

Defaults

  • PHP requests in your browser will need to use the localhost domain (127.0.0.1).
  • PHP files will have to be saved somewhere within the C:\xampp\htdocs folder.

الترجمة:

  • طلبات PHP في متصفحك يجب أن تستخدم نطاق localhost (أو 127.0.0.1).
  • ملفات PHP يجب أن تُحفظ داخل مجلد C:\xampp\htdocs.

3. جولة سريعة في PHP (Quick Tour of PHP)

3.1 نظرة عامة (Overview)

Original

  • PHP, like JavaScript, is a dynamically typed language.
  • It uses classes and functions.
  • Its consistent with other object-oriented languages such as C++, C#, and Java.
  • The syntax for loops, conditionals, and assignment is identical or same to JavaScript.
  • Differs when you get to functions, classes, and in how you define variables.

الترجمة:

  • PHP، مثل JavaScript، لغة ديناميكية النوع (dynamically typed).
  • تستخدم الأصناف والدوال.
  • متسقة مع لغات كائنية التوجه مثل C++ و C# و Java.
  • صياغة الحلقات والشروط والإسناد مطابقة لـ JavaScript.
  • تختلف في الدوال والأصناف وطريقة تعريف المتغيرات.

3.2 وسوم PHP (PHP Tags)

Original

The most important fact about PHP is that the programming code can be embedded directly within an HTML file. A PHP file will usually have the extension .php. Programming code must be contained within an opening <?php tag and a matching closing ?> tag. Any code outside the tags is echoed directly out to the client.

الترجمة: أهم حقيقة عن PHP أن الكود يمكن تضمينه مباشرة داخل ملف HTML. ملف PHP عادةً يكون امتداده .php. يجب أن يكون الكود محصورًا بين وسم الفتح <?php ووسم الإغلاق المطابق ?>. أي كود خارج الوسوم يُطبع مباشرة إلى العميل.

  $user = "Randy";

3.5 المتغيرات في PHP (Variables)

Original

  • Variables in PHP are dynamically typed.
  • Variables are also loosely typed — a variable can be assigned different data types over time.
  • To declare a variable you must preface the variable name with the dollar ($) symbol.

الترجمة:

  • المتغيرات في PHP ديناميكية النوع.
  • وهي مرنة (loosely typed) — يمكن إسناد أنواع بيانات مختلفة لنفس المتغير بمرور الوقت.
  • لتعريف متغير يجب أن تسبق اسمه بعلامة الدولار $.
$count = 42;

3.7 الثوابت (Constants)

Original

  • A constant is somewhat similar to a variable, but its value never changes.
  • Typically defined near the top of a PHP file via the define() function.
  • Once defined, it can be referenced without using the $ symbol.

الترجمة:

  • الثابت يشبه المتغير إلى حد ما، لكن قيمته لا تتغير أبدًا.
  • يُعرَّف عادةً في أعلى ملف PHP عبر الدالة define().
  • بمجرد تعريفه، يمكن الإشارة إليه دون استخدام رمز $.

Listing 8.4 — Constants

<?php

# Uppercase for constants is a programming convention
define("DATABASE_LOCAL",    "localhost");
define("DATABASE_NAME",     "ArtStore");
define("DATABASE_USER",     "Fred");
define("DATABASE_PASSWORD", "F5\7%ad");

# notice no $ prefixes constant names
$db = new mysqli(DATABASE_LOCAL, DATABASE_USER, DATABASE_PASSWORD, DATABASE_NAME);

?>

3.8 الإخراج: echo & ربط النصوص (Output & Concatenation)

echo() — long form and shortcut

echo ("hello");  // long form
echo "hello";    // shortcut

ربط النصوص (Concatenation): تُربط النصوص باستخدام معامل الربط .:

$username = "World";
echo "Hello " . $username;
// Output: Hello World

3.9 أمثلة ربط النصوص (Concatenation Examples)

Example One — فروق علامات الاقتباس

$firstName = "Pablo";
$lastName  = "Picasso";

echo "<em>" . $firstName . " " . $lastName . "</em>";
echo "<em> $firstName $lastName </em>";   // يعمل
echo '<em>' . $firstName . ' ' . $lastName . '</em>';
echo '<em> $firstName $lastName </em>';   // Won't Work!!

ملاحظة: السطر الأخير لن يعمل — علامات الاقتباس المفردة لا تُفسّر المتغيرات. الناتج سيكون النص الحرفي: <em> $firstName $lastName </em>.

Example Two — اقتباس مفرد ومزدوج متكافئان

echo "<h1>";
echo '<h1>';
// both produce the same output

Example Three — استخدام Escape

echo '<img src="23.jpg">';
echo "<img src=\"23.jpg\">";
// both produce the same output

3.11 أمثلة الإخراج عبر <img> و <a>

echo '<a href="artist.php?id=' . $id . '">' . $firstName . ' ' . $lastName . '</a>';
// Output: <a href="artist.php?id=23">Pablo Picasso</a>

3.12 PrintF

Original

You can use the printf() function — derived from the same-named function in the C programming language. It includes variations to print to string and files (sprintf, fprintf).

الترجمة: يمكنك استخدام الدالة printf() — مشتقة من الدالة التي تحمل نفس الاسم في لغة C. تتضمن تنويعات للطباعة إلى نص أو ملفات (sprintf، fprintf).

PrintF — Illustrated Example

$product = "box";
$weight  = 1.56789;

printf("The %s is %.2f pounds", $product, $weight);
// Output: The box is 1.57 pounds.
  • %s — Placeholder للنصوص.
  • %.2f — Precision specifier (رقم عشري بمنزلتين).

Precision

Original

Precision allows control over how many decimal places are shown. Important for displaying calculated numbers in a "pretty" way. Achieved with a period (.) followed by a number.

الترجمة: تسمح الدقة (Precision) بالتحكم في عدد المنازل العشرية المعروضة. مهم لعرض الأرقام المحسوبة بشكل "جميل". تتحقق بوضع نقطة . متبوعة برقم يحدد عدد الأرقام العشرية.
