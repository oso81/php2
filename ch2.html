1. المصفوفات في PHP (PHP Arrays)

1.1 مفهوم المصفوفة (Array Concept)

Original

An array is a data structure that: collects a number of related elements together in a single variable; allows the set to be iterated; allows access of any element. Since PHP implements an array as a dynamic structure: you can add to the array and remove from the array.

الترجمة: المصفوفة (Array) هي بنية بيانات تقوم بـ: جمع عدد من العناصر المترابطة معًا في متغير واحد؛ السماح بالمرور على المجموعة (Iterate)؛ السماح بالوصول إلى أي عنصر. وبما أن PHP تنفّذ المصفوفة كبنية ديناميكية: يمكنك الإضافة إلى المصفوفة والحذف منها.

1.2 المفاتيح والقيم (Array Keys & Values)

Original — Keys

  • In PHP an array is actually an ordered map, which associates each value in the array with a key.
  • Array keys are the means by which you refer to single elements in the array.
  • In most programming languages array keys are limited to integers, start at 0, and go up by 1.
  • In PHP, array keys must be either integers or strings and need not be sequential.
  • If you don't explicitly define them they are 0, 1, ...

الترجمة:

  • في PHP، المصفوفة هي في الحقيقة خريطة مرتبة (Ordered Map) تربط كل قيمة في المصفوفة بمفتاح.
  • مفاتيح المصفوفة هي الوسيلة التي تشير بها إلى عناصر مفردة داخل المصفوفة.
  • في معظم لغات البرمجة، مفاتيح المصفوفة محصورة بالأعداد الصحيحة، وتبدأ من 0 وتزيد بمقدار 1.
  • في PHP، مفاتيح المصفوفة يجب أن تكون إما أعدادًا صحيحة أو نصوصًا، ولا يلزم أن تكون متسلسلة.
  • إذا لم تُعرّفها بشكل صريح، فإنها تكون 0، 1، ...

Original — Values

Array values, unlike keys, are not restricted to integers and strings. They can be any object, type, or primitive supported in PHP.

الترجمة: قيم المصفوفة، على عكس المفاتيح، ليست محصورة بالأعداد الصحيحة والنصوص. يمكن أن تكون أي كائن أو نوع أو قيمة أولية يدعمها PHP.

1.3 إنشاء المصفوفات (Defining an Array)

Original

The following declares an empty array named days: $days = array();. You can also initialize it with a comma-delimited list of values inside the () braces using either of two syntaxes.

الترجمة: السطر التالي يعرّف مصفوفة فارغة باسم $days. يمكنك أيضًا تهيئتها بقائمة قيم مفصولة بفواصل داخل الأقواس باستخدام إحدى الصيغتين.

$days = array("Mon", "Tue", "Wed", "Thu", "Fri");
$days = ["Mon", "Tue", "Wed", "Thu", "Fri"]; // alternate syntax

1.4 الوصول إلى القيم (Accessing Array Values)

Original

To access values in an array you refer to their key using the square bracket notation.

الترجمة: للوصول إلى القيم في المصفوفة، تشير إلى مفتاحها باستخدام صيغة الأقواس المربعة.

echo "Value at index 1 is " . $days[1];

1.5 مفاتيح صريحة (Explicit Keys)

Original

In PHP, you are also able to explicitly define the keys in addition to the values. This allows you to use keys other than the classic 0, 1, 2, ..., n to define the indexes of an array.

الترجمة: في PHP، يمكنك أيضًا تعريف المفاتيح صراحةً بالإضافة إلى القيم. هذا يتيح لك استخدام مفاتيح أخرى غير المفاهيم الكلاسيكية 0، 1، 2، ... n لتحديد فهارس المصفوفة.

$days = array(0 => "Mon", 1 => "Tue", 2 => "Wed", 3 => "Thu", 4 => "Fri");

// Array with string keys, integer values
$forecast = array("Mon" => 40, "Tue" => 47, "Wed" => 52, "Thu" => 40, "Fri" => 37);

echo $forecast["Tue"]; // outputs 47
echo $forecast["Thu"]; // outputs 40

1.6 المصفوفات متعددة الأبعاد (Multidimensional Arrays)

Original

Multidimensional arrays are created by nesting arrays inside arrays. Access to elements is done by chaining multiple bracket notations.

الترجمة: المصفوفات متعددة الأبعاد تُنشأ بتداخل مصفوفات داخل مصفوفات. يتم الوصول إلى العناصر بتسلسل عدة أقواس مربعة.

$month = array(
    array("Mon", "Tue", "Wed", "Thu", "Fri"),
    array("Mon", "Tue", "Wed", "Thu", "Fri"),
    array("Mon", "Tue", "Wed", "Thu", "Fri"),
    array("Mon", "Tue", "Wed", "Thu", "Fri")
);

echo $month[0][3]; // outputs Thu

Another Example — Shopping Cart

$cart = array();
$cart[] = array("id" => 37,  "title" => "Burial at Ornans", "quantity" => 1);
$cart[] = array("id" => 345, "title" => "The Death of Marat", "quantity" => 1);
$cart[] = array("id" => 63,  "title" => "Starry Night", "quantity" => 1);

echo $cart[2]["title"]; // outputs: Starry Night

1.7 التكرار عبر المصفوفة (Iterating through an Array)

Listing 9.2 — while, do while, and for

// while loop
$i = 0;
while ($i < count($days)) {
    echo $days[$i] . "<br>";
    $i++;
}

// do-while loop
$i = 0;
do {
    echo $days[$i] . "<br>";
    $i++;
} while ($i < count($days));

// for loop
for ($i = 0; $i < count($days); $i++) {
    echo $days[$i] . "<br>";
}

Listing 9.3 — foreach (values and keys)

// foreach: iterating through the values
foreach ($forecast as $value) {
    echo $value . "<br>";
}

// foreach: iterating through values AND keys
foreach ($forecast as $key => $value) {
    echo "day " . $key . " = " . $value;
}

1.8 الإضافة إلى المصفوفة (Adding to an Array)

Original

An element can be added to an array simply by using a key/index that hasn't been used. A new element can be added to the end of any array using the empty bracket notation.

الترجمة: يمكن إضافة عنصر إلى المصفوفة ببساطة باستخدام مفتاح/فهرس لم يُستخدم من قبل. ويمكن إضافة عنصر جديد إلى نهاية أي مصفوفة باستخدام الأقواس المربعة الفارغة.

$days[5] = "Sat";   // explicit key
$days[]  = "Sun";   // next sequential key

Skipping indices + print_r()

$days = array("Mon", "Tue", "Wed", "Thu", "Fri");
$days[7] = "Sat";
print_r($days);
// Output:
// Array ( [0] => Mon [1] => Tue [2] => Wed [3] => Thu [4] => Fri [7] => Sat )

1.9 الحذف من المصفوفة (Deleting from an Array)

Listing 9.4 — unset() + array_values()

$days = array("Mon", "Tue", "Wed", "Thu", "Fri");
unset($days[2]);
unset($days[3]);
print_r($days);
// Array ( [0] => Mon [1] => Tue [4] => Fri )

$days = array_values($days);
print_r($days);
// Array ( [0] => Mon [1] => Tue [2] => Fri )

الترجمة: unset() تحذف العنصر لكنها لا تعيد ترقيم الفهارس. array_values() تعيد ترقيم الفهارس من جديد.

1.10 التحقق من وجود قيمة بـ isset()

Listing 9.5 — nonsequential keys + isset()

$oddKeys = array(1 => "hello", 3 => "world", 5 => "!");

if (isset($oddKeys[0])) {
    // never reached — $oddKeys[0] is not set
    echo "there is something set for key 0";
}

if (isset($oddKeys[1])) {
    echo "there is something set for key 1, namely " . $oddKeys[1];
}

الترجمة: isset() تعيد true إذا كانت القيمة موجودة، وfalse إذا لم تكن موجودة.

1.11 ترتيب المصفوفة (Array Sorting)

sort() vs asort()

// sort() by value — loses keys
sort($days);
print_r($days);
// Array ( [0] => Fri [1] => Mon [2] => Sat [3] => Sun [4] => Thu [5] => Tue [6] => Wed )

// asort() preserves key-value association
asort($days);
print_r($days);
// Array ( [4] => Fri [0] => Mon [5] => Sat [6] => Sun [3] => Thu [1] => Tue [2] => Wed )

الترجمة: sort() ترتب حسب القيمة وتفقد المفاتيح الأصلية. asort() ترتب حسب القيمة وتحافظ على ارتباط المفاتيح بالقيم.

1.13 مثال على gettype() — أنواع البيانات

Original

<?php
$name    = 'Mohammad';
$number  = 100;
$double  = 100.0236;
$boolean = true;
$test;   // undefined variable

print gettype($name);    print "<br>";
print gettype($number);  print "<br>";
print gettype($double);  print "<br>";
print gettype($boolean); print "<br>";
print gettype($test);
?>

الترجمة: هذه الدالة gettype() تُظهر نوع المتغير. يمكن استخدامها لفحص الأنواع التي تدعمها PHP: string، integer، double (float)، boolean، و NULL للمتغير غير المعرّف.

2. مصفوفات $_GET و $_POST الفائقة

2.1 المصفوفات الفائقة (Superglobal Arrays)

Original

PHP uses special predefined associative arrays called superglobal variables. They allow the programmer to easily access HTTP headers, query string parameters, and other commonly needed information. They are called superglobal because they are always in scope, and always defined.

الترجمة: يستخدم PHP مصفوفات ترابطية خاصة معرّفة مسبقًا تُسمى المتغيرات الفائقة (Superglobal Variables). تتيح للمبرمج الوصول بسهولة إلى ترويسات HTTP، ومعاملات سلسلة الاستعلام (Query String)، وغيرها من المعلومات الشائعة. سُميت "فائقة" لأنها دائمًا في النطاق (in scope)، ودائمًا معرّفة.

المصفوفة الوصف
$_GET Array of query string data passed to the server via the URL. — مصفوفة بيانات سلسلة الاستعلام المرسلة إلى الخادم عبر URL.
$_POST Array of query string data passed to the server via the HTTP header. — مصفوفة بيانات سلسلة الاستعلام المرسلة إلى الخادم عبر ترويسة HTTP.
$_REQUEST Array containing the contents of $_GET, $_POST, and $_COOKIES. — مصفوفة تحتوي على محتويات $_GET و $_POST و $_COOKIES.
$_SESSION Array that contains session data. — مصفوفة تحتوي على بيانات الجلسة.
$_SERVER Array containing information about the request and the server. — مصفوفة تحتوي على معلومات عن الطلب والخادم.

2.2 $_GET و $_POST

Original

The $_GET and $_POST arrays are the most important superglobal variables in PHP since they allow the programmer to access data sent by the client in a query string.

الترجمة: المصفوفتان $_GET و $_POST هما أهم المتغيرات الفائقة في PHP؛ لأنهما تتيحان للمبرمج الوصول إلى البيانات المرسلة من العميل عبر سلسلة الاستعلام.

Original — GET vs POST

  • GET requests parse query strings into the $_GET array.
  • POST requests are parsed into the $_POST array.

الترجمة:

  • طلبات GET تُحلَّل سلاسل الاستعلام فيها إلى مصفوفة $_GET.
  • طلبات POST تُحلَّل إلى مصفوفة $_POST.

مثال متكامل — GET

HTML Form + Browser + HTTP Request + PHP

<!-- HTML (client) -->
<form action="processLogin.php" method="GET">
    Name <input type="text" name="uname" />
    Pass <input type="text" name="pass" />
    <input type="submit">
</form>

<!-- Browser fills in: Name=ricardo, Pass=pw01 -->
<!-- HTTP Request -->
GET processLogin.php?uname=ricardo&pass=pw01

PHP (server) — processLogin.php

<?php
// within file processLogin.php
echo $_GET["uname"]; // outputs ricardo
echo $_GET["pass"];  // outputs pw01
?>

📌 الفرق الجوهري بين GET و POST:

  • GET: البيانات تظهر علنًا في شريط العنوان (URL)، ولها حد أقصى للطول، ومناسبة لعمليات القراءة والبحث.
  • POST: البيانات تُرسل داخل جسم الطلب (Request Body)، ولا تظهر في URL، وتسمح بأحجام كبيرة — مناسبة للمعلومات الحساسة ورفع الملفات.

2.4 الوصول إلى بيانات النموذج كـ Array (Accessing Form Array Data)

Original

Sometimes in HTML forms you might have multiple values associated with a single name. If the user selects more than one day and submits the form, the $_GET['day'] value will only contain the last value selected.

الترجمة: أحيانًا في نماذج HTML، قد يكون لديك قيم متعددة مرتبطة باسم واحد. إذا اختار المستخدم أكثر من يوم وأرسل النموذج، فإن القيمة $_GET['day'] ستحتوي فقط على القيمة الأخيرة المختارة.

Listing 9.7 — Multiple values for one name (BEFORE fix)

<form method="get">
  Please select days of the week you are free.<br />
  Monday <input type="checkbox" name="day" value="Monday" /> <br />
  Tuesday <input type="checkbox" name="day" value="Tuesday" /> <br />
  Wednesday <input type="checkbox" name="day" value="Wednesday" /> <br />
  Thursday <input type="checkbox" name="day" value="Thursday" /> <br />
  Friday <input type="checkbox" name="day" value="Friday" /> <br />
  <input type="submit" value="Submit">
</form>

المشكلة: سيُرسل يوم واحد فقط (آخر يوم مختار) إلى الخادم.

The Fix — change name="day" to name="day[]"

Monday <input type="checkbox" name="day[]" value="Monday" />
Tuesday <input type="checkbox" name="day[]" value="Tuesday" />

Listing 9.8 — PHP code to display array of checkbox variables

<?php
echo "You submitted " . count($_GET['day']) . " values";
foreach ($_GET['day'] as $d) {
    echo $d . " ";
}
?>

الترجمة: بعد التعديل، المتغير $_GET['day'] أصبح مصفوفة. نستخدم count() لعدّ القيم وforeach للمرور عليها.

2.5 استخدام Query String في الروابط (Using Query Strings in Links)

Original

Imagine a web page in which we are displaying a list of book links. One approach would be to have a separate page for each book. A better approach is to use a single page with a query string that identifies the book.

الترجمة: تخيل صفحة ويب تعرض قائمة بروابط كتب. إحدى الطرق هي تخصيص صفحة منفصلة لكل كتاب. الطريقة الأفضل هي استخدام صفحة واحدة مع query string يحدد الكتاب.

Bad approach — separate page per book

<a href="elementaryAlgebra.php">Elementary Algebra</a>
<a href="curiousWriter.php">The Curious Writer</a>
<a href="usingMIS.php">Using MIS</a>
<a href="databaseProcessing.php">Database Processing</a>

Good approach — one displayBook.php with query string

<a href="displayBook.php?isbn=0132145375">Database Processing</a>

الترجمة: رابط واحد فقط، مع ?isbn=0132145375 كـ query string يحدد الكتاب. هذا يقلل تكرار الكود.

📌 ملاحظة:

سنتعلم المزيد عن كيفية تنفيذ هذه الصفحات باستخدام قاعدة البيانات في الفصل الحادي عشر.

2.6 تنقية Query Strings (Sanitizing Query Strings)

Original

The process of checking user input for incorrect or missing information and examining SQL injection attacks is sometimes referred to as the process of sanitizing (check) user inputs.

الترجمة: عملية التحقق من مدخلات المستخدم بحثًا عن معلومات غير صحيحة أو مفقودة وفحص هجمات SQL Injection تُسمى أحيانًا عملية تنقية (sanitizing) مدخلات المستخدم.

⚠️ قاعدة أساسية: جميع قيم البيانات التي قد يُعدّلها المستخدم — مثل query strings، أو قيم النماذج، أو قيم الكوكيز — يجب تنقيتها قبل الاستخدام.

Listing 9.9 — Simple sanitization of query string values

// This uses a database API . . . we will learn about it in Chapter 11
$pid = mysql_real_escape_string($link, $_GET['id']);

if (is_int($pid)) {
    // Continue processing as normal
} else {
    // Error detected. Possibly a malicious user
}

2.7 مثال على المصفوفة الترابطية

Original

Associative array is an array that uses named keys that you assign to values that are requested by array name.

الترجمة: المصفوفة الترابطية هي مصفوفة تستخدم مفاتيح مسماة تُسندها إلى القيم، ويتم طلبها باسم المصفوفة.

Example

<?php
// simple array
$data = array("Marwa", "Alhadi");
echo $data[0];
?>

<?php
// associative array
$data = array("first" => "Marwa", "last" => "Alhadi");
echo "my first name is $data[first] and my last name is $data[last].";
?>

3. مصفوفة $_SERVER

3.1 مصفوفة معلومات الخادم

Original

$_SERVER is a superglobal array containing information about the request and the server, created and populated by the web server (such as Apache).

الترجمة: $_SERVER مصفوفة فائقة تحتوي على معلومات عن الطلب والخادم، يُنشئها ويُغذّيها خادم الويب (مثل Apache).

من أهم عناصر المصفوفة في المقرر:

  • $_SERVER['PHP_SELF']: returns the filename of the currently executing script relative to document root. — يعيد اسم ومسار الملف الحالي بالنسبة لجذر المستند (مثل /test.php).
  • $_SERVER['SERVER_NAME']: returns the host/server name. — يعيد اسم المضيف أو الخادم.
  • $_SERVER['REQUEST_METHOD']: returns the request method (e.g., 'GET' or 'POST'). — يعيد طريقة الطلب المستخدمة.
  • $_SERVER['HTTP_USER_AGENT']: returns the client's browser / OS info. — يعيد معلومات نصية عن متصفح ونظام تشغيل العميل.

مثال عملي

<?php
echo "مسار السكريبت الحالي: " . $_SERVER['PHP_SELF'] . "<br>";
echo "طريقة الطلب المستخدمة: " . $_SERVER['REQUEST_METHOD'];
?>

📌 تنبيه:

ليست كل المفاتيح مضمونة الوجود في كل البيئات؛ فهي تتأثر بالخادم والإعدادات وطريقة التشغيل (CLI vs Web Server).

3.2 مخطط ترويسات HTTP (HTTP Request Headers)

يوضح المخطط كيف تُترجم ترويسات HTTP (التي يرسلها العميل) إلى مفاتيح في $_SERVER. كما يُظهر المفاتيح المتعلقة بمعلومات الخادم نفسه:

POST /page.php HTTP/1.1
Date: Sun, 20 May 2012 23:59:59 GMT
Host: www.mysite.com
User-Agent: Mozilla/4.0
Accept-Encoding: gzip
Connection: Keep-Alive
...

<html> ...

ترويسات الطلب (HTTP Request Header) →
  $_SERVER['REQUEST_METHOD']
  $_SERVER['REQUEST_TIME']
  $_SERVER['SERVER_PROTOCOL']
  $_SERVER['HTTP_HOST']
  $_SERVER['HTTP_USER_AGENT']
  $_SERVER['HTTP_ACCEPT_ENCODING']
  $_SERVER['HTTP_CONNECTION']
// من ملفات إعدادات الخادم:
$_SERVER['SERVER_NAME']   // site name
$_SERVER['SERVER_ADDR']   // IP of server
$_SERVER['SERVER_PORT']

3.3 مفاتيح معلومات الخادم (Server Information Keys)

المفتاح الوصف
SERVER_NAMEيحتوي على اسم الموقع المطلوب.
SERVER_ADDRيعيد IP الخادم.
DOCUMENT_ROOTالموقع الذي تُشغّل منه السكريبت حاليًا.
SCRIPT_NAMEالمفتاح الذي يحدد السكريبت الفعلي الجاري تنفيذه.

3.4 مفاتيح ترويسات الطلب (Request Header Keys)

المفتاح الوصف
REQUEST_METHODطريقة الطلب: GET، HEAD، POST، PUT.
REMOTE_ADDRعنوان IP للطالب.
HTTP_USER_AGENTنظام التشغيل والمتصفح اللذان يستخدمهما العميل.
HTTP_REFERERعنوان الصفحة التي أحالتنا إلى هذه الصفحة (إن وُجد) عبر رابط.

Example — print all $_SERVER keys

<?php
foreach ($_SERVER as $key => $value) {
    echo $key . ' - ';
    if (!is_array($value)) {
        echo $key . '=' . $value . '<br>';
    }
}
?>

3.5 تحذير أمني (Security — Headers can be forged)

⚠️ الترويسات يمكن تزويرها (Forged)!

  • ترويسة HTTP_REFERER يمكن أن تكذب بشأن مصدر الإحالة.
  • USER_AGENT يمكن أن يكذب بشأن نظام التشغيل والمتصفح الذي يستخدمه العميل.

الخلاصة: لا تعتمد على ترويسات HTTP في اتخاذ قرارات أمنية حساسة.

4. مصفوفة $_FILES — رفع الملفات

4.1 مصفوفة الملفات المرفوعة

Original

$_FILES is a superglobal associative array of items uploaded to the current script via the HTTP POST method using multipart/form-data. It stores descriptive information and properties of files uploaded from the client to the server.

الترجمة: $_FILES مصفوفة ترابطية فائقة تحتوي على العناصر المرفوعة إلى السكريبت الحالي عبر طريقة HTTP POST باستخدام multipart/form-data. تخزّن معلومات وصفية وخصائص الملفات المرفوعة من العميل إلى الخادم.

شروط رفع الملفات في HTML

لرفع الملفات بنجاح من متصفح العميل إلى الخادم، يجب توفر شرطين حاسمين في نموذج HTML:

  1. تحديد طريقة الإرسال برمجيًا لتكون method="POST".
  2. إضافة الخاصية enctype="multipart/form-data" في وسم النموذج <form>.

نموذج رفع ملفات كامل

<form action="upload.php" method="POST" enctype="multipart/form-data">
    <input type="file" name="userfile" />
    <input type="submit" value="رفع الملف" />
</form>

مكونات $_FILES['userfile'] الخمسة

العنصر الوظيفة
$_FILES['userfile']['name'] الاسم الأصلي للملف على جهاز العميل.
$_FILES['userfile']['type'] نوع MIME للملف المرفوع كما أرسله المتصفح (مثل "image/gif").
$_FILES['userfile']['size'] حجم الملف المرفوع بالبايت (Bytes).
$_FILES['userfile']['tmp_name'] المسار المؤقت للملف على الخادم.
$_FILES['userfile']['error'] رمز الخطأ المرتبط برفع الملف (0 عند النجاح).

رموز أخطاء الرفع (UPLOAD_ERR_*)

الرمز القيمة المعنى
UPLOAD_ERR_OK0تم رفع الملف بنجاح دون أخطاء.
UPLOAD_ERR_INI_SIZE1حجم الملف يتجاوز الحد المسموح في php.ini.
UPLOAD_ERR_FORM_SIZE2حجم الملف يتجاوز الحد المنسوب في النموذج عبر MAX_FILE_SIZE.
UPLOAD_ERR_NO_FILE4لم يتم اختيار أو رفع أي ملف.

تأمين رفع الملفات

  1. التحقق قبل النقل: التحقق من الحجم والأخطاء ودالة is_uploaded_file().
  2. نقل الملف المؤقت: باستخدام الدالة المعيارية move_uploaded_file().
  3. المخاطر والتحذيرات الأمنية:
    • عدم الوثوق بـ $_FILES['userfile']['type']: قيمته قابلة للتعديل والتزييف من قبل العميل.
    • فحص امتداد الملف: منع رفع ملفات قد تُنفذ أكوادًا خبيثة (مثل .php).
    • تغيير اسم الملف: إعادة تسمية الملفات لمنع إتلاف ملفات النظام أو File Overwrite.

مثال معالجة رفع ملف

<?php
$targetDir  = "/var/www/uploads/";
$targetFile = $targetDir . basename($_FILES['userfile']['name']);

if (move_uploaded_file($_FILES['userfile']['tmp_name'], $targetFile)) {
    echo "تم رفع الملف ونقله بنجاح!";
} else {
    echo "خطأ في عملية الرفع!";
}
?>

4.2 مفاتيح مصفوفة $_FILES بالتفصيل

Original

The $_FILES array contains a key=value pair for each file uploaded in the POST. The key is the name attribute from the HTML form. The value is an array containing: name, type, tmp_name, error, size.

الترجمة: مصفوفة $_FILES تحتوي على زوج مفتاح=قيمة لكل ملف مرفوع في POST. المفتاح هو خاصية name من نموذج HTML. القيمة هي مصفوفة تحتوي على: name، type، tmp_name، error، size.

Concrete values

echo $_FILES["file1"]["name"];     // "Sample1.png"
echo $_FILES["file1"]["type"];     // "image/png"
echo $_FILES["file1"]["tmp_name"]; // "/tmp/phpJ08pVh"
echo $_FILES["file1"]["error"];    // 0
echo $_FILES["file1"]["size"];     // 1219038
المفتاح الوصف
nameالاسم الكامل للملف على جهاز العميل، بما في ذلك الامتداد.
typeنوع الملف.
tmp_nameالمسار الكامل لموقع التخزين المؤقت على الخادم.
errorعدد صحيح يُشفّر الأخطاء الممكنة، ويُضبط على UPLOAD_ERR_OK (القيمة 0) إذا نجح الرفع.
sizeعدد صحيح يمثل حجم الملف المرفوع بالبايت.

4.3 التحقق من الأخطاء (Check for Errors)

Listing 9.13 — Checking each file uploaded for errors

foreach ($_FILES as $fileKey => $fileArray) {
    if ($fileArray["error"] != UPLOAD_ERR_OK) {
        // error
        echo "Error: " . $fileKey . " has error " . $fileArray["error"] . "<br>";
    } else {
        // no error
        echo $fileKey . " Uploaded successfully";
    }
}

الترجمة: لكل ملف مرفوع، هناك قيمة خطأ في $_FILES. القيمة UPLOAD_ERR_OK تعني النجاح، ويجب البحث عنها قبل المتابعة.

3. Via PHP (الأساسي)

Listing 9.16 — The only one you HAVE to do

4.5 تحديد نوع الملف (Limiting the Type of File Upload)

Original

What if you wanted the user to upload an image and they uploaded a Microsoft Word document? You might want to limit the uploaded image to certain image types, such as jpg and png, while disallowing bmp and others. You should examine: (1) the file extension, and (2) the type field.

الترجمة: ماذا لو أردت من المستخدم رفع صورة فرفع مستند Word؟ قد ترغب في تقييد الصورة المرفوعة بأنواع معينة (jpg و png) ومنع bmp وغيرها. يجب أن تفحص: (1) امتداد الملف، و(2) حقل النوع.

Listing 9.17 — PHP code to look for valid mime types and extensions

$validExt  = array("jpg", "png");
$validMime = array("image/jpeg", "image/png");

foreach ($_FILES as $fileKey => $fileArray) {
    $extension = end(explode(".", $fileArray["name"]));
    if (in_array($fileArray["type"], $validMime) &&
        in_array($extension, $validExt)) {
        echo "all is well. Extension and mime types valid";
    } else {
        echo $fileKey . " Has an invalid mime type or extension";
    }
}

5. قراءة وكتابة الملفات (Reading/Writing Files)

5.1 إدارة الملفات في PHP

Original

File management in PHP involves opening channels of communication with files to read content or write new data into them. PHP provides many built-in functions for this purpose.

الترجمة: تتضمن إدارة الملفات في PHP فتح قنوات اتصال مع الملفات لقراءة المحتوى أو كتابة بيانات جديدة فيها. يوفر PHP العديد من الدوال المدمجة لهذا الغرض.

5.2 الدالة fopen()

Original

Opens a file or URL and binds it to a stream resource. Syntax: $handle = fopen(filename, mode);

الترجمة: دالة فتح الملفات؛ تفتح الملف بالمسار المحدد وتجهّز ممر البيانات (Resource) بالنمط المختار. الصيغة: $handle = fopen(filename, mode);

النمط الوصف
'r'للقراءة فقط (يبدأ من بداية الملف).
'w'للكتابة (يمسح المحتوى القديم أو ينشئ ملفًا جديدًا).
'a'للإلحاق في نهاية الملف (لا يمسح المحتوى).
 
$fp = fopen("store.txt", "w"); // فتح الملف لغرض الكتابة

5.3 الدالة fwrite()

Original

Writes the contents of a string to the file stream referenced by the file handle. Syntax: fwrite($handle, $string);

الترجمة: دالة كتابة البيانات؛ تكتب السلسلة النصية في مؤشر الملف المفتوح. الصيغة: fwrite($handle, $string);

fwrite($fp, "Hello World"); // يكتب النص داخل الملف المفتوح $fp

5.4 الدالة fread()

Original

Reads up to a specified number of bytes from the open file handle. Syntax: $data = fread($handle, length);

الترجمة: دالة قراءة حجم محدد من الملف المفتوح. الصيغة: $data = fread($handle, length);

$data = fread($fp, 1024); // قراءة 1024 بايت من الملف

5.5 الدالة fclose()

Original

Closes an open file pointer stream. Syntax: fclose($handle);

الترجمة: إغلاق ممر الملف المفتوح وتحرير موارد النظام. الصيغة: fclose($handle);

5.6 الدالة file_get_contents()

Original

Reads an entire file into a string. Syntax: $content = file_get_contents(filename);

الترجمة: دالة مساعدة لقراءة كامل محتوى الملف أو الرابط دفعة واحدة وإرجاعه كسلسلة نصية بدون الحاجة لاستخدام fopen أو fclose الصريحة. الصيغة: $content = file_get_contents(filename);

📌 الخلاصة:

  • قراءة/كتابة يدوية: fopen() → fread()/fwrite() → fclose().
  • قراءة كاملة سريعة: file_get_contents() (بدون فتح/إغلاق صريح).
  • كتابة كاملة سريعة: file_put_contents() (غير مذكور صراحة لكن شائع).

5.7 Stream Access vs All-In-Memory Access

Original

There are two basic techniques for reading/writing files in PHP:

الترجمة: هناك تقنيتان أساسيتان لقراءة/كتابة الملفات في PHP:

التقنية الوصف متى تُستخدم
Stream Access يقرأ الكود جزءًا صغيرًا فقط من الملف في كل مرة. يتطلب برمجة أكثر حرصًا، لكنه الأكثر كفاءة في الذاكرة للملفات الكبيرة جدًا. الملفات الكبيرة جدًا.
All-In-Memory Access يقرأ الملف بأكمله في الذاكرة. غير مناسب للملفات الكبيرة، لكنه يجعل معالجة الملف سهلة للغاية. الملفات الصغيرة والمتوسطة.

5.8 Stream Access — الدوال الأساسية

Original

fopen() takes a file location or URL and access mode as parameters. It allows opening, reading and writing a file even if it doesn't exist. Use fread() or fgets() to read ahead in the file. fclose() is invoked when you are done. Writing is done much the same with fwrite().

الترجمة: تأخذ fopen() موقع الملف أو URL ونمط الوصول كمعاملات. تسمح بفتح وقراءة وكتابة ملف حتى لو لم يكن موجودًا. استخدم fread() أو fgets() للقراءة من الملف. تُستدعى fclose() عند الانتهاء. الكتابة تتم بنفس الطريقة باستخدام fwrite().

📌 أنماط fopen() بالتفصيل:

النمط الوصف
'r'قراءة فقط. يبدأ من بداية الملف. لا يمكن الكتابة.
'r+'قراءة وكتابة. يبدأ من بداية الملف.
'w'كتابة فقط. يمسح المحتوى القديم أو ينشئ ملفًا جديدًا.
'w+'قراءة وكتابة. يمسح المحتوى القديم أو ينشئ ملفًا جديدًا.
'a'إلحاق فقط. يفتح الملف للإلحاق في نهايته (لا يمسح المحتوى).
'a+'قراءة وإلحاق. يفتح الملف للقراءة والإلحاق.

Listing 9.19 — Opening, reading lines, and closing a file

$f = fopen("sample.txt", "r");
$ln = 0;
while ($line = fgets($f)) {
    $ln++;
    printf("%2d: ", $ln);
    echo $line . "<br>";
}
fclose($f);

الترجمة: يفتح الملف للقراءة 'r'، ثم يستخدم fgets() لقراءة سطر واحد في كل مرة حتى نهاية الملف، وأخيرًا يغلق الملف بـ fclose().

5.9 In-Memory File Access — الدوال المساعدة

Original

Three helper functions make in-memory file access easy:

  • file() — reads the entire file into an array, with each array element corresponding to one line in the file.
  • file_get_contents() — reads the entire file into a string variable.
  • file_put_contents() — writes the contents of a string variable out to a file.

الترجمة: ثلاث دوال مساعدة تجعل الوصول إلى الملفات في الذاكرة أمرًا سهلًا:

الدالة الوظيفة
file()تقرأ الملف بالكامل إلى مصفوفة، بحيث يقابل كل عنصر سطرًا واحدًا في الملف.
file_get_contents()تقرأ الملف بالكامل إلى متغير نصي.
file_put_contents()تكتب محتوى متغير نصي إلى ملف.

أمثلة

// read entire file into a variable
$fileAsString = file_get_contents(FILENAME);

// write the contents of $writeme to a file
file_put_contents(FILENAME, $writeme);

5.10 تحليل ملف CSV بفواصل (Parsing a Comma-Delimited File)

Original — Sample paintings.txt

01070, Picasso, The Actor, 1904
01080, Picasso, Family of Saltimbanques, 1905
02070, Matisse, The Red Madras Headdress, 1907
05010, David, The Oath of the Horatii, 1784

الترجمة: تخيل ملفًا نصيًا مفصولًا بفواصل يحتوي على معلومات عن لوحات فنية، حيث يقابل كل سطر لوحة مختلفة.

Listing 9.20 — Processing a comma-delimited file

// read the file into memory; if there is an error then stop processing
$paintings = file($filename) or die('ERROR: Cannot find file');

// our data is comma-delimited
$delimiter = ',';

// loop through each line of the file
foreach ($paintings as $painting) {

    // returns an array of strings where each element
    // corresponds to each substring between the delimiters
    $paintingFields = explode($delimiter, $painting);

    $id     = $paintingFields[0];
    $artist = $paintingFields[1];
    $title  = $paintingFields[2];
    $year   = $paintingFields[3];

    // do something with this data
}

الترجمة: تقرأ file() الملف بالكامل إلى مصفوفة (كل سطر عنصر). يمر foreach على كل سطر، ويستخدم explode() لتقسيم السطر إلى حقول مفصولة بفاصلة.

7. جداول المقارنة (Comparison Tables)

7.1 Indexed Array vs Associative Array

وجه المقارنة Indexed Array Associative Array
نوع المفتاح أعداد صحيحة (0, 1, 2...) سلاسل نصية (مثل 'name')
الإنشاء التلقائي PHP تُرقّم تلقائيًا إن أُهمل المفتاح يلزم تحديد المفاتيح صراحة
الاستخدام الشائع القوائم المتسلسلة سجلات البيانات ذات المسميات

7.2 $_GET vs $_POST

وجه المقارنة $_GET $_POST
مكان نقل البيانات في رابط URL بعد علامة ? داخل جسم الطلب (Request Body)
الحجم محدود بحجم URL يسمح بأحجام كبيرة
الاستخدام الملائم القراءة والبحث إرسال كلمات المرور ورفع الملفات

7.3 $_SERVER vs $_FILES

وجه المقارنة $_SERVER $_FILES
مصدر البيانات خادم الويب والبيئة التشغيلية ملفات العميل المرفوعة عبر POST
المحتوى المسارات، طريقة الطلب، اسم المضيف أسماء الملفات، الحجم، النوع، الأخطاء

7.4 Superglobal vs Normal Variable

وجه المقارنة Normal Variable Superglobal
النطاق (Scope) محلي — يتطلب global للوصول داخل الدوال عام تلقائي — متاح في كل مكان
التسمية ينشئه المطور ($var) مسميات مبنية مسبقًا ($_POST, $_GET...)
