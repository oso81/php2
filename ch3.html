1. نظرة عامة على البرمجة كائنية التوجه (Object-Oriented Overview)

1.1 مقدمة (Overview)

Original

PHP is a full-fledged object-oriented language which simulates reality. For example, if we have a class called Human has some attributes such as name, age, grade and he/she has operations (activities) such as reading, writing and walking. PHP supports object-oriented language so it's called strong language. PHP is a full-fledged object-oriented language with many of the syntactic constructs popularized in languages like Java and C++. Earlier versions of PHP do not support all of these object-oriented features — PHP versions after 5.0 do.

الترجمة: PHP هي لغة كائنية التوجه بالكامل، وتُحاكي الواقع. على سبيل المثال، إذا كان لدينا صنف يُسمى Human له سمات مثل الاسم والعمر والدرجة، وله عمليات (أنشطة) مثل القراءة والكتابة والمشي. PHP تدعم البرمجة كائنية التوجه، ولذلك تُسمى لغة قوية. PHP لغة كائنية التوجه بالكامل مع العديد من التركيبات النحوية الشائعة في لغات مثل Java و C++. الإصدارات القديمة من PHP لا تدعم كل هذه الميزات الكائنية — الإصدارات بعد 5.0 تدعمها.

📌 ملاحظة:

PHP هي لغة كائنية التوجه بالكامل، لكن دعم الميزات الكائنية الكاملة بدأ من الإصدار 5.0.

1.2 المصطلحات (Terminology)

Original

Each variable created from a class is called an object or instance, and each object maintains its own set of variables, and behaves (largely) independently from the class once created. An item (object) allows the developer to think about particular properties (also called attributes or data members) and methods (functions).

الترجمة: كل متغير يُنشأ من صنف يُسمى كائن (Object) أو نسخة (Instance)، وكل كائن يحتفظ بمجموعة متغيراته الخاصة، ويتصرف (إلى حد كبير) بشكل مستقل عن الصنف بمجرد إنشائه. العنصر (الكائن) يسمح للمطور بالتفكير في خصائص (Properties) معينة — تُسمى أيضًا سمات (Attributes) أو متغيرات أعضاء (Data Members) — ودوال (Methods).

1.3 العلاقة بين الصنف والكائن (Relationship between Class and Objects)

Example — Book Class

Book class — Defines properties such as: title, author, and number of pages.
Objects (or instances of the Book class) — Each instance has its own title, author, and number of pages property values.

الترجمة:

  • الصنف Book: يُعرّف خصائص مثل العنوان والمؤلف وعدد الصفحات.
  • الكائنات (Objects): نسخ من الصنف Book، ولكل نسخة قيم خاصة بها للعنوان والمؤلف وعدد الصفحات.

1.4 لغة النمذجة الموحدة (UML — Unified Modelling Language)

Original

The standard diagramming notation for object-oriented design is UML (Unified Modeling Language). Class diagrams and object diagrams, in particular, are useful to us when describing the properties, methods, and relationships between classes and objects. UML is a set of graphical techniques to describe software design.

الترجمة: التدوين القياسي للمخططات في التصميم كائني التوجه هو UML (لغة النمذجة الموحدة). مخططات الأصناف (Class Diagrams) ومخططات الكائنات (Object Diagrams) مفيدة بشكل خاص عند وصف الخصائص والدوال والعلاقات بين الأصناف والكائنات. UML هي مجموعة من التقنيات الرسومية لوصف تصميم البرمجيات.

1.5 كائنات الخادم مقابل كائنات سطح المكتب (Server and Desktop Objects)

Original

What is the difference between web programming and desktop application programming? Object in web programming is created (normally) and a PHP object is loaded into memory only for the life of that HTTP request. In desktop software, the object must be recreated and loaded into memory for each request that requires.

الترجمة: ما الفرق بين برمجة الويب وبرمجة تطبيقات سطح المكتب؟ الكائن في برمجة الويب يُنشأ (عادةً) ويُحمَّل كائن PHP في الذاكرة فقط خلال عمر طلب HTTP ذلك. أما في برمجيات سطح المكتب، فيجب إعادة إنشاء الكائن وتحميله في الذاكرة لكل طلب يتطلب ذلك.

وجه المقارنة Desktop Application Web Application (PHP)
عمر الكائن يبقى في الذاكرة طالما التطبيق يعمل. يُنشأ ويُدمَّر مع كل HTTP Request.
إعادة الإنشاء مرة واحدة عند بدء التطبيق. مع كل طلب جديد.
الذاكرة ذاكرة واحدة مشتركة (Desktop memory). ذاكرة مستقلة لكل طلب (Request A / B / C).

2. الأصناف والكائنات في PHP (Classes and Objects in PHP)

2.1 تعريف الأصناف في PHP (Defining Classes in PHP)

Original

The PHP syntax for defining a class uses the class keyword followed by the class name and {} braces.

الترجمة: صياغة PHP لتعريف صنف تستخدم الكلمة المفتاحية class متبوعة باسم الصنف والأقواس المعقوفة {}.

Listing 10.1 — A simple Artist class

<?php
class Artist {
    public $firstName;
    public $lastName;
    public $birthDate;
    public $birthCity;
    public $deathDate;
}
?>

📌 ملاحظة تاريخية:

قبل الإصدار 5 من PHP، كانت الكلمة المفتاحية var تُستخدم لتعريف خاصية (بدلًا من public).

2.2 إنشاء الكائنات (Instantiating Objects in PHP)

Original

Defining a class is not the same as using it. To make use of a class, one must instantiate (create) objects from its definition using the new keyword.

الترجمة: تعريف الصنف لا يعني استخدامه. للاستفادة من الصنف، يجب إنشاء كائنات من تعريفه باستخدام الكلمة المفتاحية new.

$picasso = new Artist();
$dali = new Artist();

2.3 الخصائص (Properties)

Original

Once you have instances of an object, you can access and modify the properties of each one separately using the variable name and an arrow (->).

الترجمة: بعد أن تحصل على كائنات، يمكنك الوصول إلى خصائص كل واحد منها وتعديلها بشكل منفصل باستخدام اسم المتغير والسهم ->.

Listing 10.2 — Instantiating two Artist objects and setting properties

<?php
$picasso = new Artist();
$dali = new Artist();

$picasso->firstName = "Pablo";
$picasso->lastName  = "Picasso";
$picasso->birthCity = "Malaga";
$picasso->birthDate = "October 25 1881";
$picasso->deathDate = "April 8 1973";
?>

2.4 الدوال البنائية (Constructors)

Original

Constructors let you specify parameters during instantiation to initialize the properties within a class right away. In PHP, constructors are defined as functions with the name __construct(). Notice that in the constructor each parameter is assigned to an internal class variable using the $this-> syntax. You must always use the $this syntax to reference all properties and methods associated with this particular instance of a class.

الترجمة: الدوال البنائية تسمح لك بتحديد معاملات أثناء إنشاء الكائن لتهيئة الخصائص داخل الصنف فورًا. في PHP، تُعرَّف الدوال البنائية كدوال باسم __construct(). لاحظ أن كل معامل في الدالة البنائية يُسند إلى متغير داخلي في الصنف باستخدام صياغة $this->. يجب دائمًا استخدام $this للإشارة إلى جميع الخصائص والدوال المرتبطة بهذه النسخة المحددة من الصنف.

Listing 10.3 — A constructor added to the class definition

<?php
class Artist {
    // variables from previous listing still go here
    public $firstName;
    public $lastName;
    public $birthDate;
    public $birthCity;
    public $deathDate;

    function __construct($firstName, $lastName, $city, $birth, $death = null) {
        $this->firstName = $firstName;
        $this->lastName  = $lastName;
        $this->birthCity = $city;
        $this->birthDate = $birth;
        $this->deathDate = $death;
    }
}
?>

Using the constructor

<?php
$picasso = new Artist("Pablo", "Picasso", "Malaga", "Oct 25, 1881", "Apr 8, 1973");
$dali    = new Artist("Salvador", "Dali", "Figures", "May 11 1904", "Jan 23 1989");
?>

📌 ملاحظة:

لاحظ استخدام $death = null كقيمة افتراضية — فبعض الفنانين لا يزالون على قيد الحياة.

2.5 الدوال (Methods)

Original

Methods are like functions, except they are associated with a class. They define the tasks each instance of a class can perform and are useful since they associate behavior with objects.

الترجمة: الدوال (Methods) تشبه الدوال العادية، لكنها مرتبطة بصنف. تحدد المهام التي يمكن لكل نسخة من الصنف أداؤها، وهي مفيدة لأنها تربط السلوك بالكائنات.

<?php
$picasso = new Artist(...);
echo $picasso->outputAsTable();
?>

Example — outputAsTable method

<?php
class Artist {
    public $firstName;
    public $lastName;
    public $birthDate;
    public $birthCity;
    public $deathDate;

    public function outputAsTable() {
        $table  = "<table>";
        $table .= "<tr><th colspan='2'>";
        $table .= $this->firstName . " " . $this->lastName;
        $table .= "</th></tr>";

        $table .= "<tr><td>Birth:</td>";
        $table .= "<td>" . $this->birthDate;
        $table .= " (" . $this->birthCity . ")</td></tr>";

        $table .= "<tr><td>Death:</td>";
        $table .= "<td>" . $this->deathDate . "</td></tr>";

        $table .= "</table>";
        return $table;
    }
}
?>

إضافة الدوال إلى UML Class Diagram

عند إضافة الدوال إلى مخطط UML، يظهر قسم جديد داخل الصنف يحتوي على أسماء الدوال ومعاملاتها:

Class (with methods)
Artist
+ firstName: String
+ lastName: String
+ birthDate: Date
+ birthCity: String
+ deathDate: Date
+ __construct(string, string, string, string, string)
+ outputAsTable() : String

2.6 مستويات الظهور (Visibility / Accessibility)

Original

The visibility of a property or method determines the accessibility of a class member and can be set to:

  • Public — the property or method is accessible to any code that has a reference to the object.
  • Private — sets a method or variable to only be accessible from within the class.
  • Protected — is related to inheritance.

الترجمة: مستوى الظهور (Visibility) لخاصية أو دالة يحدد إمكانية الوصول إلى عضو الصنف، ويمكن ضبطه على:

  • public (عام): الخاصية أو الدالة متاحة لأي كود لديه مرجع للكائن.
  • private (خاص): يجعل الدالة أو المتغير متاحًا فقط من داخل الصنف.
  • protected (محمي): مرتبط بالوراثة (سنتعلمه لاحقًا في قسم Inheritance).

UML Visibility Diagram — Painting class

class Painting {
    public  $title;
    private $profit;

    public function doThis() {
        $a = $this->profit;             // ✅ مسموح (داخل الصنف)
        $b = $this->title;              // ✅ مسموح
        $c = $this->doSecretThat();     // ✅ مسموح
    }

    private function doSecretThat() {
        $a = $this->profit;             // ✅ مسموح
        $b = $this->title;              // ✅ مسموح
    }
}

// من خارج الصنف:
$p1 = new Painting();
$x = $p1->title;                    // ✅ مسموح (public)
$y = $p1->profit;                   // ❌ غير مسموح (private)
$p1->doThis();                      // ✅ مسموح (public)
$p1->doSecretThat();                // ❌ غير مسموح (private)

📌 رموز UML لمستويات الظهور:

  • + = public
  • − = private
  • # = protected

2.7 الأعضاء الساكنة (Static Members)

Original

A static member is a property or method that all instances of a class share. Static members use the self:: syntax and are not associated with one object. They can be accessed without any instance of an Artist object by using the class name, that is, via Artist::$artistCount.

الترجمة: العضو الساكن (Static Member) هو خاصية أو دالة تشترك فيها جميع نسخ الصنف. الأعضاء الساكنة تستخدم صياغة self:: ولا ترتبط بكائن واحد. يمكن الوصول إليها دون أي نسخة من كائن Artist باستخدام اسم الصنف، أي عبر Artist::$artistCount.

Listing 10.5 — Class definition modified with static members

<?php
class Artist {
    public static $artistCount = 0;
    public $firstName;
    public $lastName;
    public $birthDate;
    public $birthCity;
    public $deathDate;

    function __construct($firstName, $lastName, $city, $birth, $death = null) {
        $this->firstName = $firstName;
        $this->lastName  = $lastName;
        $this->birthCity = $city;
        $this->birthDate = $birth;
        $this->deathDate = $death;
        self::$artistCount++;
    }
}
?>

📌 الفرق الجوهري:

  • الخاصية العادية ($firstName): لكل كائن نسخة مستقلة منها.
  • الخاصية الساكنة (self::$artistCount): نسخة واحدة مشتركة بين جميع الكائنات.

Static Members في UML

في مخطط UML، يُشار إلى الأعضاء الساكنة بخط سفلي (underline) على اسم الخاصية/الدالة:

UML Representation
Artist

+ firstName: String

2.8 ثوابت الصنف (Class Constants)

Original

Constant values can be stored more efficiently as class constants so long as they are not calculated or updated (such as string). They are added to a class using the const keyword. Unlike all other variables, constants don't use the $ symbol when declaring or using them. Accessed both inside and outside the class using self::EARLIEST_DATE in the class and classReference::EARLIEST_DATE outside.

الترجمة: يمكن تخزين القيم الثابتة بكفاءة أكبر كثوابت صنف، بشرط ألا تكون محسوبة أو محدَّثة (مثل النصوص). تُضاف إلى الصنف باستخدام الكلمة المفتاحية const. على عكس كل المتغيرات الأخرى، الثوابت لا تستخدم رمز $ عند تعريفها أو استخدامها. يمكن الوصول إليها من داخل الصنف وخارجه عبر self::EARLIEST_DATE داخل الصنف، وClassName::EARLIEST_DATE خارجه.

Example — Class Constant

<?php
class Artist {
    const EARLIEST_DATE = 'January 1, 1200';

    // ... باقي الخصائص والدوال

    public function getEarliestAllowedDate() {
        return self::EARLIEST_DATE;  // الوصول من داخل الصنف
    }
}

// الوصول من خارج الصنف:
echo Artist::EARLIEST_DATE;
?>

3. التصميم كائني التوجه (Object-Oriented Design)

3.1 تغليف البيانات (Data Encapsulation)

Original

Perhaps the most important advantage to object-oriented design is the possibility of encapsulation, which generally refers to restricting access to an object's internal components. Another way of understanding encapsulation is: it is the hiding of an object's implementation details. A properly encapsulated class will define an interface to the world in the form of its public methods, and leave its data, that is, its properties, hidden (that is, private).

الترجمة: ربما تكون أهم ميزة للتصميم كائني التوجه هي إمكانية التغليف (Encapsulation)، والذي يشير عمومًا إلى تقييد الوصول إلى المكونات الداخلية للكائن. طريقة أخرى لفهم التغليف: هو إخفاء تفاصيل تنفيذ الكائن. الصنف المُغلَّف بشكل صحيح يُعرّف واجهة للعالم في صورة دواله العامة (public methods)، ويترك بياناته (أي خصائصه) مخفية (أي private).

3.2 دوال الجلب والتعديل (Getters and Setters)

Original

If a properly encapsulated class makes its properties private, then how do you access them? Using getters and setters. A getter to return a variable's value is often very straightforward and should not modify the property. Setter methods modify properties, and allow extra logic to be added to prevent properties from being set to strange values.

الترجمة: إذا كان الصنف المُغلَّف بشكل صحيح يجعل خصائصه خاصة (private)، فكيف تصل إليها؟ باستخدام دوال الجلب (Getters) ودوال التعديل (Setters). دالة الجلب التي تُرجع قيمة متغير غالبًا ما تكون واضحة جدًا، ولا يجب أن تُعدّل الخاصية. دوال التعديل تُعدّل الخصائص، وتسمح بإضافة منطق إضافي لمنع ضبط الخصائص على قيم غريبة.

Getter Example

<?php
public function getFirstName() {
    return $this->firstName;
}
?>

Setter Example — with validation

<?php
public function setBirthDate($birthdate) {
    // set variable only if passed a valid date string
    $date = date_create($birthdate);
    if (! $date) {
        $this->birthDate = $this->getEarliestAllowedDate();
    } else {
        $this->birthDate = $date;
    }
}
?>

3.3 الوراثة (Inheritance)

Original

Inheritance enables you to create new PHP classes that reuse, extend, and modify the behavior that is defined in another PHP class. A class that is inheriting from another class is said to be a subclass or a derived class. The class that is being inherited from is typically called a superclass or a base class. A PHP class is defined as a subclass by using the extends keyword.

الترجمة: الوراثة تتيح لك إنشاء أصناف PHP جديدة تُعيد استخدام وتوسّع وتعدّل السلوك المُعرَّف في صنف PHP آخر. الصنف الذي يرث من صنف آخر يُسمى صنفًا فرعيًا (Subclass) أو صنفًا مشتقًا (Derived Class). الصنف الذي يورث منه يُسمى عادةً الصنف الأعلى (Superclass) أو الصنف الأساسي (Base Class). يُعرَّف صنف PHP كصنف فرعي باستخدام الكلمة المفتاحية extends.

<?php
class Painting extends Art {
    // ...
}
?>

UML Inheritance Diagram

يوضح مخطط UML أن Painting يرث من Art — يُشار إلى الوراثة بسهم مثلث مفتوح الرأس يشير من الابن إلى الأب:

Class يملك يمتد من
Art − name
− artist
− createdYear
+ __toString()
+ getName()
+ setName()		 —
Painting − medium
+ getMedium()
+ setMedium()		 extends Art

Example usage

<?php
$p = new Painting();
echo $p->getName();    // defined in base class (Art)
echo $p->getMedium();  // defined in subclass (Painting)
?>

3.4 مستوى الوصول المحمي (Protected Access Modifier)

Original

If you want a member to be available to subclasses but not anywhere else, you can use the protected access modifier.

الترجمة: إذا أردت أن يكون عضو متاحًا للأصناف الفرعية ولكن ليس في أي مكان آخر، يمكنك استخدام معدّل الوصول protected.

Example — protected methods

<?php
class Art {
    private $name;
    private $original;

    public  function getName()      { return $this->name; }
    public  function setName($n)    { $this->name = $n; }
    protected function getOriginal() { return $this->original; }
    protected function setOriginal($o) { $this->original = $o; }
    private function init()        { /* ... */ }
}
?>

// من صفحة أو صنف آخر:
$p = new Painting();
$a = new Art();

$w = $p->getOriginal();   // ❌ غير مسموح (protected - من خارج الوراثة)
$y = $a->getOriginal();   // ❌ غير مسموح (protected - من خارج الصنف)

📌 ملخص مستويات الوصول الثلاثة:

  • public: متاح من أي مكان.
  • protected: متاح من داخل الصنف والأصناف المورثة فقط.
  • private: متاح من داخل الصنف نفسه فقط.

3.5 تعدد الأشكال (Polymorphism)

Original

Polymorphism is the notion that an object can in fact be multiple things at the same time. Consider an instance of a Painting object named $guernica created as follows: $guernica = new Painting("1937", $picasso, "Guernica", "Oil on canvas");. The variable $guernica is both a Painting object and an Art object due to its inheritance.

الترجمة: تعدد الأشكال (Polymorphism) هو فكرة أن الكائن يمكن أن يكون في الحقيقة عدة أشياء في نفس الوقت. اعتبر نسخة من كائن Painting باسم $guernica منشأة كالتالي: $guernica = new Painting("1937", $picasso, "Guernica", "Oil on canvas");. المتغير $guernica هو في نفس الوقت كائن Painting وكائن Art بسبب الوراثة.

Polymorphism in action

<?php
$picasso = new Artist("Pablo", "Picasso", "Malaga", "Oct 25, 1881", "Apr 8, 1973");

// create the paintings
$guernica = new Painting("1937", "Picasso", "Guernica", "Oil on canvas");
$chicago  = new Sculpture("1967", "Picasso", "Chicago", 454);

// create an array of art
$works = array();
$works[0] = $guernica;
$works[1] = $chicago;

// to test polymorphism, loop through art array
foreach ($works as $art) {
    // the beauty of polymorphism:
    // the appropriate __toString() method will be called!
    echo $art;
}
?>

📌 جوهر تعدد الأشكال:

هذا يعني أن كائنين من نفس النوع يمكن أن يكون لهما تطبيقات مختلفة بنفس الاسم، كما في مثال Painting / Sculpture — كلاهما يرث من Art، وكلاهما يُعيد تعريف __toString() بطريقته الخاصة.

3.6 الواجهات (Interfaces)

Original

An object interface is a way of defining a formal list of methods that a class must implement without specifying their implementation. Interfaces are defined using the interface keyword, and look similar to standard PHP classes, except an interface contains no properties and its methods do not have method bodies defined.

الترجمة: واجهة الكائن (Interface) هي طريقة لتعريف قائمة رسمية بالدوال التي يجب على الصنف تطبيقها دون تحديد تنفيذها. تُعرَّف الواجهات باستخدام الكلمة المفتاحية interface، وتبدو مشابهة لأصناف PHP القياسية، إلا أن الواجهة لا تحتوي على خصائص، ودوالها لا تحتوي على أجسام محددة.

Defining the interface

<?php
interface Viewable {
    public function getSize();
    public function getPNG();
}
?>

Implementing the interface

<?php
class Painting extends Art implements Viewable {
    public function getPNG() {
        // return image data would go here
    }
    public function getSize() {
        // return image size would go here
    }
}
?>

📌 ملاحظة:

عندما يُقال إن الصنف Painting يُنفّذ واجهة Viewable، فهذا يعني أنه يجب أن يوفّر تطبيقات لدوال getSize() وgetPNG().

Listing 10.11 — Painting class implementing an interface

<?php
interface Viewable {
    public function getSize();
    public function getPNG();
}

class Painting extends Art implements Viewable {
    public function getPNG() {
        // return image data would go here ...
    }
    public function getSize() {
        // return image size would go here ...
    }
}
?>

مثال موسّع على الواجهات

يوضح المخطط التالي أن:

  • Viewable واجهة تُطبقها Painting وMovie — فيها getSize() وgetPNG().
  • Playable واجهة تُطبقها Movie وSong — فيها getLength() وgetMedia().
  • كلها ترث من الصنف الأساسي Art.

3.7 الأصناف المجرّدة (Abstract Classes)

Original

An abstract class is a class that contains functionality required by all other classes. Abstract classes cannot be instantiated directly, and force subclasses to implement their abstract methods.

الترجمة: الصنف المجرّد (Abstract Class) هو صنف يحتوي على وظائف تتطلبها جميع الأصناف الأخرى. لا يمكن إنشاء كائنات من الأصناف المجرّدة مباشرة، وتُجبر الأصناف الفرعية على تطبيق دوالها المجرّدة.

Extended Example — Abstract Class Art

<?php
/**
 * The abstract class that contains functionality
 * required by all types of Art
 */
abstract class Art {
    private $name;
    private $artist;
    private $yearCreated;

    // ... constructor, getters, setters

    abstract public function __toString();
}
?>

Painting — requires a "medium"

<?php
class Painting extends Art {
    private $medium;

    // ... constructor, getters, setters

    public function __toString() {
        return parent::__toString() . ", Medium: " . $this->getMedium();
    }
}
?>

Sculpture — has weight

<?php
class Sculpture extends Art {
    private $weight;

    // ... constructor, getters, setters

    public function __toString() {
        return parent::__toString() . ", Weight: " . $this->getWeight() . "kg";
    }
}
?>
